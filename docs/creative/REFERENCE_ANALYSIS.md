# Reference Analysis Protocol

## Objective
Extract generalizable creative patterns from a small representative sample. Do not reproduce protected expression.

## Inputs
- Channel URL and description
- 5–10 representative Shorts
- Optional transcript/subtitles
- Optional sampled frames with timestamps

## Analyze
1. Channel promise and audience
2. Repeated story structures
3. Hook patterns
4. Scene count and duration distribution
5. Visual style and composition
6. Camera language
7. Character movement and expression
8. Animation timing and transitions
9. Typography and captions
10. Narration, music, and sound effects
11. Retention devices and payoff
12. Variations and outliers

## Evidence discipline
For every important finding, record:
- Observation
- Evidence: video filename and timestamp/frame
- Interpretation
- Confidence: high/medium/low

Separate observed facts from hypotheses. If the sample does not support a conclusion, say so.

## Output files
- `creative/reference-analysis.md`
- `creative/patterns.json`
- `creative/open-questions.md`

Do not reanalyze the same reference set for each new Short. Revisit only when the channel strategy or visual language changes.
