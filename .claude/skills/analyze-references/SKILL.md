# Analyze References

Read `docs/creative/REFERENCE_ANALYSIS.md`. Inventory the supplied media. Prefer existing transcripts and representative sampled frames over repeatedly processing entire videos.

Delegate bounded analysis to `reference-analyst`. Ask it to save detailed findings in files and return only a concise summary.

After analysis:
- check that observations have timestamps or file evidence
- separate facts from hypotheses
- identify repeated patterns vs one-off choices
- list uncertainty and missing evidence
- avoid copying protected expression

Do not rerun this workflow for each new Short. Reuse the saved analysis and style bible.
